# AI Tool Usage

Tools used: ChatGPT and VS code.

ChatGPT was primarily used for architecture discussions, debugging,
test design, and documentation. The IDE assistant was used for code
completion and local implementation assistance.

AI assistance was used to:

- brainstorm and refine the agent architecture
- help implement and debug LangGraph orchestration
- generate and refine test cases
- troubleshoot API, LLM, and frontend integration issues
- review error traces and suggest fixes
- improve documentation and README structure

I validated the resulting implementation manually and through the automated
test suite.

The final implementation was tested end-to-end, with the current automated
suite passing all 40 tests.
